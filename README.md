# flavono123 퍼즐

작고 짧은 퍼즐들.

첫 게임은 **시시오도시** (`/sozu`). 가케히를 돌려 샘물을 연못까지 나르고, 시시오도시는 탁 소리로 사슴을 쫓아요. 물은 위에서 아래로만 흘러요.

스테이지는 주소로 공유할 수 있어요.

- 경로: `/sozu/8`
- 쿼리: `/sozu?stage=8`

앞 정원을 이 기기에서 아직 안 깼다면, 공유 주소는 잠겨 있고 가장 앞에 남은 정원으로 안내해요.

```
pnpm dev
```

스테이지 해가 닫히는지 보려면:

```
pnpm dlx tsx src/games/sozu/check.ts
```
